# كورة أرينا — نسخة Render

حزمة مستقلة عن Sites، تتضمن الموقع العربي والمشغل ولوحة إدارة محمية.

## النشر
1. ضع ملفات هذه الحزمة في مستودع Git خاص بحسابك.
2. في Render اختر New ثم Blueprint واربط المستودع. يحدد render.yaml خطة Free وDocker تلقائيًا.
3. اضبط أسرار XTREAM_SERVER وXTREAM_USERNAME وXTREAM_PASSWORD دون إضافتها للمستودع.
4. يُولد ADMIN_PASSWORD تلقائيًا بواسطة مخطط Render؛ احفظه من لوحة Render. اسم المدير الافتراضي admin.
5. افتح رابط الخدمة، ثم /admin لتسجيل دخول المدير. لا تكتب بيانات الدخول في رابط الموقع.

بديل يدوي: New Web Service، اختر Docker وFree. اضبط ADMIN_USERNAME وADMIN_PASSWORD وبيانات البث كمتغيرات سرية. أمر التشغيل node server.mjs، والمنفذ يؤخذ من PORT.

## التحقق المحلي
node test.mjs
node server.mjs

## الحماية
الهوية المرسلة من الزائر في ترويسات Sites تُحذف بالكامل؛ تسجيل المدير مستقل باسم وكلمة مرور محفوظين على الخادم. كل مسارات الإدارة محمية قبل عرض البيانات. لا تُعاد كلمة مرور البث للمتصفح. تُخفي روابط المشغل بيانات المزوّد باستخدام التشفير. تُحدَّث بيانات الاشتراك من إعدادات Render، وليس من نموذج داخل الموقع.

## حدود النسخة المجانية
خطة Render المجانية مخصصة للتجربة والاستخدام المحدود. تنام الخدمة بعد 15 دقيقة دون طلبات، ولها حدود نقل بيانات وقد تُعلق عند الاستهلاك المرتفع. لا تضمن الحزمة توزيع بث جماعي مجانيًا دون حدود. لم يُختبر اشتراك بث حقيقي لأن بيانات الدخول غير متوفرة. رابط خدمة جديد غير منشور بعد؛ يلزم ربط حساب Render وإكمال النشر.
